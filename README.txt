مشروع منصة فرسان ابن الوليد للاختبارات المركزية

الملفات:
- index.html : ملف المنصة الرئيسي مع شعار وزارة التعليم وشعار المدرسة ولوحة الإنجاز.
- students.json : أسماء الطلاب ورموز الدخول المشفرة.
- .nojekyll : ملف مساعد للنشر على GitHub Pages.

طريقة النشر على GitHub Pages:
1) ارفع الملفات إلى مستودع GitHub.
2) من Settings ثم Pages اختر Deploy from a branch.
3) اختر main و /root ثم Save.
